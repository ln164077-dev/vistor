# Bcare Customer Site Export

This archive contains the current project source prepared for local editing.

Excluded for safety and size: `.env` files and secrets, `node_modules`, build output, Git metadata, runtime logs, coverage files, and archives.

After extraction, install dependencies with `pnpm install`. Environment variables must be configured locally from your secure project settings; do not commit `.env` files. The project currently contains existing TypeScript issues in some converted pages, so run the available checks before making changes.
